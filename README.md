# NEON ARENA

### A 2D Isometric Cyberpunk Arena Shooter

**NEON ARENA** is an action-focused, isometric arena shooter created by **Umar Aziz** and published under **Synckerz**.

Fight through neon-lit combat zones, face increasingly dangerous enemies, and push through **32 sectors across 4 chapters**.

## The game

- **Genre:** Isometric arena shooter
- **Setting:** Cyberpunk / science fiction
- **Structure:** 4 chapters · 32 sectors
- **Developer:** Umar Aziz
- **Publisher:** Synckerz
- **Engine:** Godot

## Chapters

| Chapter | Sectors |
|---|---:|
| Neon District | 5 |
| Toxic Wasteland | 7 |
| Frost Core | 9 |
| Omega Fortress | 11 |
| **Total** | **32** |
